**An all-in-one platform for discovering, creating, and managing events — with real-time updates, AR previews, and more!**

## 🚀 Overview
EventEase is a cross-platform mobile application built using **Flutter & Dart**, backed by **Firebase**, designed to enhance the way users interact with events. Whether you're an event-goer or an organizer, EventEase makes it seamless to explore, host, and manage events — all in one app.

## 🧠 Key Features
- 🔍 **Event Discovery** – Browse and search for nearby or trending events with filters.
- 🧾 **Ticketing System** – Book tickets with secure in-app payments.
- 📆 **Calendar Integration** – Sync events directly with your personal calendar.
- 👓 **AR Previews** – Get a virtual sneak peek of venues using Augmented Reality.
- 🔄 **Real-Time Updates** – Stay up-to-date with live changes in event schedules or capacity.
- 📱 **Social Media Sharing** – Share events instantly via social platforms.
- 🛠️ **Admin Panel for Organizers** – Manage registrations, edit event info, and view analytics in real time.

## 🧰 Tech Stack
- **Frontend:** Flutter, Dart  
- **Backend & Database:** Firebase (Firestore, Auth, Storage, Functions)  
- **Other Services:** Google Maps API, Razorpay/Stripe for payments, ARCore/ARKit for AR previews

## 🛠️ Getting Started

### Prerequisites
- Flutter SDK
- Firebase Project setup
- Emulator or physical device

### Installation
```bash
git clone https://github.com/your-username/EventEase.git
cd EventEase
flutter pub get


Firebase Setup
Create a Firebase project

Enable Firestore, Auth (Email/Google), and Storage

Add google-services.json (Android) and GoogleService-Info.plist (iOS) in appropriate directories

Use your Firebase config in lib/services/firebase_config.dart

Run the App
 flutter run

🔐 Environment Variables (Optional)
Add API keys and sensitive configs in .env or secrets.dart file:

dart
const String GOOGLE_MAPS_API_KEY = "your-api-key";
const String PAYMENT_GATEWAY_KEY = "your-secret-key";
